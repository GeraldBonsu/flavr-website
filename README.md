# Flavr — Marketing Site & Investor Deck

The public-facing marketing site and investor deck for **Flavr**, an AI recipe app that turns what's already in your kitchen into a recipe worth cooking.

## Why this exists

This repo is the landing page and pitch materials used to introduce Flavr to users and investors — it is not the product itself. For the actual app, see:
- [`flavr-v2`](https://github.com/GeraldBonsu/flavr-v2) — the current product (Next.js + Supabase + Claude)
- [`flavr.`](https://github.com/GeraldBonsu/flavr.) — the earlier consumer MVP

## What's in here

- `index.html` — the marketing landing page
- `investor-deck.html` — the investor pitch deck
- `api/` — supporting serverless functions

## Running locally

Static HTML, no build step — serve the directory with any static file server, or open `index.html` directly.
